# Démarrage rapide — Français

Godot 4.7 est requis. Copiez `addons/fableweld_characters` dans le dossier `addons/` du projet, puis activez le module dans Paramètres du projet → Extensions. Dans le panneau Fableweld Characters, choisissez Français et **Ajouter le kit Lumen** dans un catalogue vide. Sélectionnez une entrée pour la modifier dans l’Inspecteur. Créez les classes avant les personnages et conservez les ID lors des mises à jour des références. Créez le dossier `data`, saisissez `res://data/characters.tres` dans **Chemin du catalogue**, puis choisissez **Enregistrer le catalogue**. Un échec d’ouverture ne remplace pas les données actuelles. **Annuler la dernière modification** annule les actions du catalogue ; l’Inspecteur utilise son propre historique. Tab parcourt les commandes. Avant une mise à jour, sauvegardez les données et gardez les catalogues hors du dossier du module. L’exemple modifiable et la démonstration exécutable sont des téléchargements facultatifs distincts. Ce module ne résout pas les combats et ne déduit pas les coûts des capacités.
