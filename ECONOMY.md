## Downloads and requirements

Only **Addon Only** is required for your own project. The editable Lumen Vale project and free Windows x64 demo are separate optional downloads. The scenery and MIT Lite world are example content; no paid Calendar implementation is bundled.

Verified on **Godot 4.7.2, Windows x64**. Other targets are unverified. The interface and guides support seven languages with built-in fallback; custom names and IDs remain yours. Translations are AI-assisted; native-speaker and physical-DPI certification is not claimed.

## Limits and saves

Shaped recipes support translation within a rectangular grid, not rotation or mirroring. There is no automatic currency exchange. Discount windows use absolute game minutes, not recurring calendar rules. Item effects, health, combat, quests and whole-game saves belong to your game. Use one writer per save path; power-loss recovery is not guaranteed.

Supported legacy Inventory migration previews the conversion and writes a separate economy file, preserving the original. Combined clock saves are excluded from that migration. Keep authored catalogs and generated scenes outside the replaceable addon folder, and test updates in a project copy first.
