# Frequently asked questions

[Home](README.md) · [Website](https://fableweld-labs.itch.io/) · [Support](SUPPORT.md)

## Where is the main website?

https://fableweld-labs.itch.io/ is Fableweld Labs' main website and storefront. GitHub supports documentation, workflow examples and bug reports.

## Is the complete RPG authoring kit available?

It is in development. Time & Seasons is the first product in release preparation. Refer to the itch.io website for products actually released; a plan or development milestone is not a released download.

## Where do I download a product?

Use its official itch.io page when available. This documentation repository does not host internal builds or Paid source archives.

## Is everything open source because this repository is public?

No. Product code is governed by the license supplied with that product and edition. This public documentation hub does not grant permission to redistribute Paid source. There is no blanket open-source license for the full Fableweld catalog.

## Which Godot versions and platforms are supported?

Support is stated per product and release. Check that release's documentation before installing or upgrading.

## Do you have executable examples?

Approved executable examples will be supplied and identified with their product release. The current [examples page](EXAMPLES.md) contains written workflow recipes.

## Where do I get help?

Use [GitHub issues](https://github.com/fableweldlabs/fableweldlabs/issues) for public bugs and documentation problems, and [email](mailto:fableweldlabs@gmail.com) for private or purchase-related questions.
