# Contributing

Thank you for helping make the documentation useful.

- Report reproducible problems using [SUPPORT.md](SUPPORT.md).
- Suggest documentation corrections with the page name, unclear passage and proposed correction.
- Keep requests focused on a concrete creator workflow and describe the result you need.
- Do not submit secrets, private project files, Paid product code or material you do not have permission to share.

This repository is the public documentation/support hub. Product implementation changes and new feature commitments are managed separately. Opening an issue does not guarantee a feature, deadline or support commitment.
