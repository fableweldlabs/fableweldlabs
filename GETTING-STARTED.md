# Getting started

[Home](README.md) · [Website and products](https://fableweld-labs.itch.io/) · [Support](SUPPORT.md)

## Before installing a product

1. Open the product's official page from the Fableweld Labs itch.io website. Use the release identified there, not an internal candidate or an unrelated mirror.
2. Check its Godot version, operating-system support, edition and included dependencies. Compatibility is product-specific; do not assume every Godot 4 release is supported.
3. Read the license and limitations supplied with that release. Free and Paid editions can have different rights and features.
4. Back up your project and saves before adding or upgrading an addon. Try its documented example in a small test project first.
5. Follow the installation and upgrade instructions shipped with the exact downloaded version. Do not install two editions into the same project unless its documentation explicitly supports that arrangement.

## Time & Seasons

[Free Lite](https://fableweld-labs.itch.io/time-seasons-free-lite) supplies the MIT clock and seasons. [Starter](STARTER.md) adds lighting, HUD, sleep, availability rules and clock saves. Each product has a small required addon and separate optional Lumen Vale examples. Starter and Lite support English, Spanish, Brazilian Portuguese, Simplified Chinese, Japanese, French and German for their interfaces, quick starts and Lumen Vale dialogue/signs.

For a practical introduction to the problems the tool is intended to solve, read the [workflow examples](EXAMPLES.md).

## If something goes wrong

Record the product/edition/version, Godot version, OS, steps taken, expected result and actual result. Include the relevant error text after removing private information. See [Support](SUPPORT.md) for the reporting route.
