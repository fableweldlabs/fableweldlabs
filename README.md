# Fableweld Labs

## Tools for living worlds

We are building modular Godot tools and visual workflows for original 2D RPGs, starting with Time & Seasons and working toward a connected RPG authoring kit.

**[Main website and storefront](https://fableweld-labs.itch.io/)** · **[Documentation](https://github.com/fableweldlabs/fableweldlabs/blob/main/GETTING-STARTED.md)** · **[Workflow examples](https://github.com/fableweldlabs/fableweldlabs/blob/main/EXAMPLES.md)** · **[Support](https://github.com/fableweldlabs/fableweldlabs/blob/main/SUPPORT.md)** · **[Report a bug](https://github.com/fableweldlabs/fableweldlabs/issues/new)**

Our itch.io website is the home for product information, release announcements, and approved downloads. This GitHub repository supports it with guidance and public bug reports.
