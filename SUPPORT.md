# Support and bug reports

[Home](README.md) · [Main website](https://fableweld-labs.itch.io/) · [Open an issue](https://github.com/fableweldlabs/fableweldlabs/issues/new)

Use GitHub issues for reproducible bugs and documentation problems. For purchase/download trouble, private questions, or information that should not be public, email [fableweldlabs@gmail.com](mailto:fableweldlabs@gmail.com). Use the marketplace's purchase-support process for payment or refund requests.

## Before opening an issue

Search existing issues and use the instructions for your exact product version. If possible, check the behavior in a minimal project.

Copy this outline into a new issue:

```text
Product, edition and version:
Godot version:
Operating system:
Renderer (for visual problems):

What I expected:
What happened:

Steps to reproduce:
1.
2.
3.

Relevant error text:
Minimal example or screenshot (only if safe and permitted to share):
```

Public issues are visible to others. Remove credentials, tokens, purchase receipts, private contact information and proprietary assets. Do not attach Paid addon source or an entire private game project. For a suspected security issue, use email rather than publishing exploit details.

Product-specific support and update terms appear with each released product. This page does not promise a response deadline, custom development, lifetime updates or support for unlisted platforms.
